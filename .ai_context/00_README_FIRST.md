> 新接入本项目的 AI 必须立即执行以下步骤，不得回答任何技术问题。

1. 读取同目录下 `01_project_brief.md`、`02_bugfix_log.md`、`03_architecture.md`、`04_constraints.md`
2. 扫描代码库中所有 `[FIX-` 标记，提取编号、文件、行号、状态
3. 与 `02_bugfix_log.md` 交叉核对，列出"有标记无记录"或"有记录无标记"的异常
4. 向用户汇报："已加载项目上下文。当前状态：X个Bug已修复，Y个待修复，Z个技术债。新Bug编号从 B00? / F00? 开始。"
5. 本文件本身不得修改，除非用户明确指令。

规则：所有后续修改必须更新 `02_bugfix_log.md` 并添加 `[FIX-XXX]` 代码标记。
